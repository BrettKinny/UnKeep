# Domain Docs

This repository uses a single-context domain layout.

Before engineering exploration, read `CONTEXT.md` at the repository root when it exists and relevant ADRs under `docs/adr/`. If they do not exist, proceed silently; producer workflows create them when domain decisions are resolved.

Use terminology defined by `CONTEXT.md` consistently. If work contradicts an ADR, surface the conflict explicitly instead of silently overriding it.
